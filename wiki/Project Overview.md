# Project Overview

Moedah POS is a modern Point of Sale system built with a [[Backend Architecture|Go backend]] and [[Frontend Architecture|Next.js frontend]].

## Tech Stack

- **Backend**: Go with Chi router
- **Frontend**: Next.js 16 with React 19
- **Database**: PostgreSQL
- **Infrastructure**: Docker, Docker Compose

## Key Features

- POS transactions
- Product management
- Customer management
- Loyalty program
- Reporting
