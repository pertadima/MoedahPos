# Loyalty System

Customer loyalty program with points earning and redemption.

## Features

- Points earning on every transaction
- Tier-based membership (Bronze, Silver, Gold)
- Points redemption for discounts
- Store-specific loyalty rates

## Database Tables

- `loyalty_points` - Point balances
- `membership_tiers` - Tier definitions
- `loyalty_ledger` - Transaction history
